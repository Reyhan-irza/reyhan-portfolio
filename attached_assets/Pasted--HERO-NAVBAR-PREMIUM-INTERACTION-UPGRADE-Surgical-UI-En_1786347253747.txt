4. HERO SCROLL-DOWN BEHAVIOR
==================================================

This is the MAIN visual upgrade.

When the user scrolls DOWN from the Hero, the Hero's decorative/icon elements should feel as if they are being naturally pulled away / fading into the page.

The effect must be:

subtle
cinematic
smooth
controlled
premium

NOT a basic:

opacity: 0 → 1

Instead combine a few subtle properties.

For example:

- opacity decreases gradually
- translateY changes slightly
- scale changes minimally
- blur may increase very slightly
- supporting icon elements can move at different speeds

Example conceptual behavior:

Hero visible:
100% opacity
scale 1
translateY 0
blur 0

Scrolling down:
opacity ↓
scale → approximately 0.97–0.99
translateY → slight upward/downward movement depending on composition
blur → 0–2px maximum if appropriate

The result should feel like the Hero is receding into the interface.

DO NOT make the entire Hero disappear abruptly.

DO NOT hide the main Hero content immediately.

The effect should happen progressively based on scroll position.
