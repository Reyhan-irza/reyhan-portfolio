---
name: Portfolio audit phase gates
description: Review and delivery boundary for the phased portfolio audit.
---

For the portfolio audit, complete one phase at a time, verify it, report the result, and wait for the user's review before starting another. Do not commit or push unless the user explicitly asks.

**Why:** The user requested review between phases and prohibited commits or pushes without instruction.

**How to apply:** Treat approval as limited to the current phase. After reporting changed files and verification, stop until the user reviews the result.
